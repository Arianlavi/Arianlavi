### 📦 [PyPack V2](https://github.com/Arianlavi/Pypack)

A modern Python packaging and executable-building tool with a clean GUI.

Features include:

* Python project packaging
* Executable building
* Obfuscation support
* UPX compression
* Custom build workflows

**Built with:** `Python` `CustomTkinter` `PyInstaller` `PyArmor`

An automated configuration collection and monitoring system powered by GitHub Actions.

Features include:

* Automated configuration collection
* Scheduled workflows
* Speed testing
* Dead configuration filtering
* Automated updates

**Built with:** `Python` `GitHub Actions` `Web Scraping`
